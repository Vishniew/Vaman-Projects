# Vaman (RP2040 + ESP32) Development Hub

This repository is a collection of projects and experiments developed for the **Vaman Board**, a powerful development platform featuring both the **RP2040** and **ESP32** microcontrollers.

The projects here explore the synergy between these two MCUs, ranging from low-level firmware development to high-level integration with Computer Vision.

---

##  Hardware Overview
The **Vaman Board** integrates two industry-leading chips:
* **RP2040:** Handles real-time tasks, GPIO control, and high-speed processing.
* **ESP32:** Provides robust Wi-Fi and Bluetooth connectivity for IoT applications.

---

##  Tech Stack & Tools

### Development Environments
* **Visual Studio Code:** Primary IDE for C-SDK and Python development.
* **Thonny:** Used for rapid prototyping with MicroPython.

### Frameworks & SDKs
* **Raspberry Pi Pico SDK (C/C++):** For high-performance RP2040 firmware.
* **Espressif IoT Development Framework (ESP-IDF):** For professional ESP32 development.
* **OpenCV:** Integrated for computer vision tasks (Object tracking, Morse decoding, etc.).
* **MicroPython:** For quick scripting and hardware testing.

---

##  Repository Content
The repository is organized into folders based on the development language and target MCU:
* **RP2040 Projects:** Includes C-SDK and MicroPython scripts for motor control, sensors, and vision feedback.
* **ESP32 Projects:** Focuses on wireless communication, IoT bridging, and ESP-IDF implementations.
* **PC Scripts:** Python-based tools and OpenCV scripts that interact with the Vaman board via Serial.
